# ANI TEACH 🧠

**Learn Smarter. Think Faster.** A responsive study-assistant website by ANI STUDIO.

## Features
- Dashboard with study activity counters
- AI Tutor-style chat interface (offline starter responses)
- Browser-based notes summarizer
- Topic-based practice quizzes
- Beginner JavaScript, Python and HTML explanations
- Study planner with tasks saved in local browser storage
- Responsive dark interface for desktop and mobile
- No build tools required

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the default branch and **/(root)**, then save.
4. Wait for GitHub Pages to publish the site.

## Important: AI connection
This first version is a functional frontend starter. The tutor uses limited, locally coded responses; it is **not connected to a live AI model**. For real AI answers, add a backend API (for example, FastAPI) and keep any AI provider secret keys on the server—never put secrets in browser JavaScript.

## Privacy
Study tasks and counters are stored in the current browser's local storage. They are not synced to an account or database.
